## 1. 凍結文（現行・v2）

確定：設計チャット19（作家判断・凍結への改訂・2026-07-29）

> **盤面スコープ原則（凍結文 v2）：**パワーアップは全て「自陣の場」に属する効果とし、自陣内にある全ての球（越境してきた球を含む）に無差別に適用され、球が自陣を出た瞬間に効果は残らない（速度は越境時に基準値へ正規化）。効果が球そのものに恒久付着すること、越境挙動を変えることは引き続き禁止。球の**数**に触れるのはマルチボールだけであり、その唯一性が反転1の手がかりとして機能する。

**改訂理由（記録）**：球側効果の採用にあたり、効果を「場」に属させることで越境の縫い目
（強化状態の漏出・切断）を構造的に消し、自球と越境球の挙動差をゼロにして偽装を強化するため。
手がかりは「球の物理に触れる唯一の例外」から「球の数に触れる唯一の例外」へ純化された。

**改訂履歴**：旧版（パドル側限定原則・handoff_設計チャット18 §1 決定⑥、作家判断・2026-07-29）は
`docs/新PJ/archive/新PJ_第3案_凍結文_パドル側限定原則_旧版_2026-07-29.md` に逐語保存済み。
旧版と現行版の違いは「パワーアップが球側に一切触れない（旧）」から
「パワーアップは場に属し、球側にも無差別適用されるが恒久付着・越境挙動変更はしない（新）」
への転換。マルチボールが球の**数**に触れる唯一の例外、という手がかり構造自体は両版で維持。

## 12. 指示書06：sticky除去と器具再割当（2026-07-30）

出所：`proto/報告_玉キープ束探索_v1_2026-07-29.md`（指示書05・sticky込み束の発見）、
`proto/報告_sticky除去再検証と較正プロト_v1.md`（指示書06）。

### 12-1. sticky killの経緯

指示書05で得たB1〜B3・B5同時充足束（catch_rate_cap=0.999等）は、リレークリア所要時間を
89〜92分まで膨張させた（目標23〜24分の約4倍）。ball_effect_magnitude（0.5〜2.0）を振っても
ほぼ緩和されなかった。原因はstickyの「球を一定秒数パドル上に保持する」性質が、保持中の球を
壁破壊の循環から除外し、リング全体のスループットを構造的に下げていたこと。

設計チャット20はこれを受け、**stickyをkillする**（パドル側アイテムを5種→4種に削減）と
判断した。B5（スティッキー保持上限）は対象が消滅したため、体験帯としてVOIDになる
（本書§6参照）。

### 12-2. 指示書05確定候補束の不採用（記録）

指示書05の最終候補束（`paddle_catch_rate_cap=0.999`・`paddle_power_bonus_per_stage`高値）は、
B1・B2をシミュ上で充足させるために抽象パドル捕球率を実卓ではあり得ない極端な値
（0.999＝ほぼ100%）へ追い込んだ結果だった。指示書06でB1・B2がシミュの判定対象から
外れたため、この極端値へ追い込む理由自体が消滅し、当該束は不採用（廃棄）とした。

### 12-3. 器具再割当（設計チャット20）

シミュレーション（`ring_sim.py`の抽象tickモデル）は、パドル試行のペース（実時間との対応）を
表現できないため、B1・B2・B5の判定器具として不適格と判断された。以後、各帯の判定器具を
以下のように再割当する。

| 帯・指標 | 判定器具 | 備考 |
|---|---|---|
| B1（落球頻度） | 較正用プロトタイプ＋プレイテスト | `proto/ring_keep_calibration.html`。実物理・実時間で実測 |
| B2（復帰期待時間） | 較正用プロトタイプ＋プレイテスト | 同上 |
| B5（スティッキー保持） | ―（対象消滅・VOID） | sticky killにより判定対象自体が消滅 |
| B3（球側効果稼働率） | シミュレーション（`item_sim.py`） | 変更なし。sticky除去後に再掃引済み（本節12-4） |
| 要求量64,672.2の成立性 | シミュレーション（`item_requirement_check.py`） | 変更なし |
| 偶発クリア率 | シミュレーション | 変更なし |
| STARVE（球涸れ） | シミュレーション | 変更なし |

## 13. 指示書07：アイテム9種化とガイド是正（2026-07-30）

### 13-1. guideの物理不介入化（案(a)）

旧実装のguideは、球をパドル中心へ寄せる引力を持っていたが、これは棄却済みのホーミング

指示書06で確定していた案(a)（予測線・自陣上端打ち切りの表示のみ・物理不介入）へ全面
差し替えた。シム上は`ITEM_CATCH_RATE_CONTRIBUTORS`から除外し、捕球率・物理に一切
寄与しない機構的不活性として実装した（ドロップ枠・LIFOスタックは占有する）。

### 13-2. アイテム9種化（clone廃止・magnet/laser/weaken採用）

設計チャット21の確定事項：

- **分身（clone）は拡大と機能軸が同一と判定され廃止**、**磁石（magnet）**に差し替え
  （落下アイテムをパドルへ引き寄せる。球には無関係）
- 新規2種を採用：**レーザー（laser）**（パドル側・自動発射・持続ダメージ）、
  **自陣弱体化（weaken）**（場・時限・第3の型＝`ITEM_FIELD_SIDE`。自陣の全ダメージを
  倍率で底上げする）
- アイテム総数：**7→9種**（パドル側5種＋球側3種＋場1種）
- ドロップテーブルは9種+抽選枠randomの10エントリだが、randomが9種均等へ再抽選される
  ため実効出現率は厳密に1/9。この等価性によりシムはrandomを実装せず9種均等抽選で代表
  （selfcheckで数学的に検算）

### 13-3. 掃引A/B・要求量再検証の結果（不合格）

- 掃引A（`drop_rate∈{0.10,0.15,0.20,0.25}×ball_effect_ticks∈{2,3,4}`の12組）でB3+weaken
  参考値を測定。8/12組がB3≤40%を満たし、`drop_rate=0.15, ball_effect_ticks=2`
  （B3=0.237）を有望束として選定
- 掃引B（laser強度3水準）を経て要求量再検証を実施した結果、**natural_clear_rate=1.80%

## 15. 指示書09：カタログ第一陣実装と複合掃引（2026-07-30）

出所：`proto/報告_カタログ第一陣と複合掃引_v1.md`（指示書09）。

### 15-1. guide表示是正（プロトのみ・束非干渉）

マッチのテスト所見「予測線が反射後にしか表示されず、アイテムとしての恩恵がない」への
対応。予測線の**表示タイミングのみ**を変更し、guide段が有効な間は常に表示するよう
是正した（サーブ待機中＝公称サーブの予測線／球が上昇中＝自陣上端まで／球が下降中＝
パドル面＝着地予測まで）。描画仕様（左右壁反射・自陣境界で打ち切り＝案(a)）とシム上の
物理不介入（§13-1）は変更していない。

### 15-2. 貫通3ヒット化

**調査結果**：プロトで貫通が約1ヒット分しか機能しない原因は、シムとプロトで貫通の
「持続の単位」が食い違っていたことだった。シムは`ball_effect_ticks`（1tick=1ヒット相当）
という**ヒット数**単位で持続していたが、プロトは`effectDurationSec`という**実時間**
単位で持続させており、対応が取れていなかった。

**是正**：貫通を「ブロックに3回ヒットするまで持続」の固定ヒット数（`PIERCE_HITS=3`。
**保護数字・掃引で短縮禁止**）へ、シム・プロトの両方で統一した。他の球側効果
（爆発・加速）は従来どおり`ball_effect_ticks=2`のまま、貫通のみ`ball_effect_ticks`から
分離した専用経路を持つ。

### 15-3. アイテム壁（確定ドロップ・ブロック）新設

設計チャット22 #5採用。Ricochet系「Power-Up Brick」方式の併存型。**各陣2個**の
アイテム壁を設置し、破壊すると必ず1アイテム（9種均等）がドロップする。既存のランダム
落下（drop_rate）はそのまま併存。

- シムは「各陣の破壊進行に伴い確定ドロップが2回発生する」を**時間連動・等間隔近似**
  （900tick窓の中でk=2個を等間隔offsetに配置し発火）で実装
- プロトは通常ブロックと区別できる緑枠の仮ブロックを各陣2個仮配置（**配置の本設計は
  レイアウト指示書送り**）
- `item_wall_bricks=0`（既定）なら確定ドロップは一切発火せず、指示書08までの挙動と
  bit-for-bit互換

### 15-4. 複合掃引（18組・relay中央値のみ全組未達）

`weaken_multiplier∈{1.3,1.5,1.7}×laser配分目標∈{5%,7%}×drop_rate∈{0.05,0.08,0.10}`の
18組を、指示書07〜09の実装変更をすべて織り込んだ上で掃引。**18組中0組が合格基準を
満たさなかったが、全18組がrelay中央値（21.3〜22.1分 vs 目標23〜24分）の1点のみで
不合格**だった。natural_clear_rateは大半の組で0%へ改善し、B2参考値も体験帯へ改善する
など、指示書07・08からの明確な前進が確認された。

**事前登録仮説**（weaken・laserの引き下げがrelayを+2分以上押し上げる）は方向は正しかったが
大きさが不足した（実測+0.44〜+1.23分）。relay中央値を支配しているのは依然として強化球
本体の壁破壊レート（staged傾斜×周回球）であり、weaken・laser・drop_rateはいずれも relay
に対しては二次的な効きしか持たないことが構造的に示された。

**最も基準に近い束：`drop_rate=0.05, weaken_multiplier=1.3, laser配分目標5%`**
（natural=0.0%・reached=100%・relay中央値=22.11分のみ不合格）。**この束が指示書10の
確定束の起点となった。**
